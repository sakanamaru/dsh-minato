# 隐私政策（Privacy Policy）

**一句话：本工具不收集、不上传、不存储你的任何数据。**

## 本工具做什么

dsh-minato 是一个**本地**工具箱，用于查看和管理你机器上 DeepSeek Harness（dsh）的状态。
它运行在你的电脑上，通过命令行读取 dsh 的本地文件与进程状态，把结果显示在界面上。

## 数据收集

| 项 | 说明 |
|---|---|
| **收集的个人数据** | **无** ✓ |
| **上传的数据** | **无** ✓ —— 本工具**不向任何服务器发送你的数据** |
| **遥测 / 统计** | **无** ✓ —— 没有埋点、没有崩溃上报、没有使用统计 |
| **账号 / 登录** | **无** ✓ —— 本工具没有账号系统 |
| **Cookie / 追踪** | **无** ✓ |

## 网络访问

本工具**仅在以下情况**访问网络，且**均为可选、可预期**：

| 场景 | 访问什么 | 触发条件 |
|---|---|---|
| 检查更新（update-info / update-center / check） | 你配置的 npm registry · GitHub Releases（取更新日志；插件缺 repository 字段时也会问 npm） | 你**主动**运行，或在「更新」页刷新时 |
| 更新 dsh（update / install） | 你配置的 npm registry | 你**主动**点「执行更新」并确认后 |
| 体检（doctor） | 你配置的 npm registry（一次连通性探测） | 你**主动**运行体检时 |
| 校验安装（verify-install --url） | 你**显式传入的那个 URL** | 只有传了 `--url` 才联网（默认不联网） |
| DeepSeek 余额（balance） | api.deepseek.com | 仅当你在设置里填了 balance_key、且**主动**查看余额时 |
| 打开浏览器 | **本机** `127.0.0.1` | 你**主动**启动 dsh web 时 |

**不会**在后台静默联网 ✓；**不会**把任何本地内容发送出去 ✓。

## 本工具读取什么

- dsh 的会话投影文件（`~/.dsh/storages/...`）—— **只读** ✓
- dsh 的配置文件与 profile 信息 —— **只读** ✓
- 本机进程与端口状态（用于判断 dsh 是否在运行）—— **只读** ✓

## 本工具写入什么

- 本工具自己的配置与日志（在**本工具自己的目录**里）
- 你**主动**创建的备份（在你指定的目录里）
- 你**主动**创建的快捷方式 / 开机自启入口 / 卸载信息
- 你**主动确认**后，修改 dsh profile 的插件配置文件（`bridge-install` / 插件「隔离·恢复」只动 `cordis.patch.yml` 这类文本）
- 你**主动**运行 `restore` 时，把选中的备份**合并回 dsh 的数据根**：写入目标是**生效数据根**（`$DSH_HOME`，未设置时**就是默认 `~/.dsh`**）✓
  —— 恢复前会**自动先做一次备份**并打印回滚锚点 `RESTORE_PRE_BACKUP` ✓；恢复是**合并语义**（只覆盖同名文件，不删除数据根里独有的文件）✓
  —— 带 `--apply` 时只允许写入隔离数据根（未设 `$DSH_HOME`，或数据根等于默认位置 → `RESTORE_FAIL` 拒绝 ✓）

除上面这些**由你主动触发**的写操作之外，**不会**修改 dsh 的任何文件 ✓ —— 只读命令与状态读取一律不写盘 ✓。

## 卸载

卸载时**默认不删除**你的 `~/.dsh` 数据 ✓ —— 那是 dsh 自己的数据，不是本工具的。
卸载过程会在桌面留一份说明文档，写明数据位置以及如何自行删除。

## 第三方

本工具**运行时零第三方依赖** ✓（详见 [ASSETS.md](ASSETS.md)）。
本工具**不嵌入**任何分析、广告或追踪 SDK ✓。
