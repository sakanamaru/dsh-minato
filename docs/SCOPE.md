# dsht 范围契约（v4）

> 本文件是**硬约束**。违反即回滚，不接受“特殊情况”。

## 形态

一个自包含 exe（Windows x64）+ 一个只读信号插件。**桌面工具箱 + 常驻 HUD**。

## 子命令（上限 8 个）

| # | 命令 | 作用 | 写入？ |
|---|---|---|---|
| 1 | `hud` | 贴边浮层：运行态/会话态/上下文压力/待答问题 | 否（读快照） |
| 2 | `diag` | 桌面端救砖：进程占用/pending/版本/完整性 → 诊断（`--fix` 才写） | `--fix` 时写 |
| 3 | `scan` | 会话健康扫描（官方真校验器） | 否 |
| 4 | `repair` | 会话修复（副本→校验→备份→apply） | `--apply` 时写 |
| 5 | `backup` | 一键备份/校验/恢复 | 写 |
| 6 | `port` | 3080 端口与占用进程排查 | 否 |
| 7 | `profile` | profile 列表 / 坏插件禁用 | `--disable` 时写 |
| 8 | `log` | 日志尾随 + 一键诊断包 | 诊断包写 |

## 纪律

1. **≤8 子命令**。新增必须先删一个，或在 PR 里证明「8 周内该删的是哪个」。
2. 每个子命令**核心逻辑 ≤300 行**，IO 与纯逻辑分离（`Core` 层不许 IO/时钟）。
3. 每个子命令必须有**会失败的断言**（`tests/` 里至少一条，删掉实现要红）。
4. 发布 **8 周后无使用证据** → 删除，不留“也许有人用”。
5. **不做**：看板/图表/成本报表/余额/插件市场/会话浏览器/主题/自建更新器。
6. 默认**只读**；所有写操作必须 `--yes` 或显式 `--fix/--apply/--disable`，且写前备份。
7. 退出码：`0` 成功 / `1` 执行失败 / `2` 用法错误 / `3` 不支持（平台/前置缺失）。
