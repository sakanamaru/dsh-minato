# Minato logo —— 含义与用法

`minato` = 港。**一枚锚**：港里最不会漂的那样东西，对应本项目的活 —— 搬稳、可核对、恢复得住。

- **环**（真孔、真透明）：闭环、可核对、有始有终
- **横杆 + 锚杆**：骨架与可预测的接口
- **两支锚爪**：抓地 —— 恢复要抓得住，不是"看起来成功了"
- **深蓝描边 `#0B2545`**：主体青 `#2BB3A3` 在浅底偏淡，深描边让边界在浅底上立得住

## 用法

- README / 发版说明顶部：`logo.svg`（矢量，推荐）或 `logo.png`，宽 **180**
- 中间尺寸用 `logo-128.png`；favicon / GUI 小图标用 `logo-64.png`（64）
- **深浅底都可用**：青主体对深底 5.92:1、对浅底 2.60:1；深蓝描边对白底 15.39:1 补足浅底边界 ✓
- 保持留白：四周留白 ≥ 图形宽度的 10%（本图已内置）· **不要**非等比拉伸、改配色、加投影、用到 16 px 以下
