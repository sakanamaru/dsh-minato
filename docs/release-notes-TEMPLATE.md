# 发版说明模板 / Release notes template

> 用法：整份复制成 `docs/release-notes-vX.Y.Z.md`（**这个文件本身不是发版说明**）。
> `v3/tools/release.ps1` 只从**这个路径**取正文，并把 `commit=` / `tag=` / `tag-ci-run=` 注入到 release body 顶部。
> 分层规则见 `docs/RELEASING.md` **§3**：**patch 用短版**（默认）· **minor 才写合并叙述**（把下面的「合并叙述」一节展开）。
> **禁止**：写"随下一版本发布"这类**注定作废**的句子；每版都写成 4k~8k 字符的长文。
>
> ── 下面从 `<!-- BEGIN -->` 起是正文，出厂的说明文件里不要留这段说明 ──

<!-- BEGIN -->
